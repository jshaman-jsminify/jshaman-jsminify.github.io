    Why JShaman-JSMinify

    Why choose JShaman-JSMinify

    Not a regex replacement: a complete Babel-AST minification pipeline that balances size, safety and modern syntax.

    Comment & whitespace cleanup

    Remove // and /* */ comments, collapse indentation, spaces and line breaks while preserving strings and template literals.

    console / debugger removal

    Remove console.log, warn, error and leftover debugger statements when those options are enabled.

    Variable, function and property mangling

    Assign short names by character frequency, with top-level renaming, reserved lists, class-name protection and property-regex mangling.

    AST-level optimization

    Remove unreachable code, merge declarations and expressions, fold constants, inline single-use variables and simple functions, and turn ifs into ternaries or short-circuits.

    Boolean and expression compression

    true → !0, false → !1, undefined → void 0, plus optional Math.pow / ** rewrites.

    ES5 to ES2022+

    Parse modern syntax and optionally downlevel the output to ES5, ES2015, ES2020 or another target.

    Source maps and nameCache

    Generate, inline and chain source maps; keep renaming stable across builds with nameCache.

    100% browser-local

    Online minification runs entirely in your browser; code is never uploaded. CLI and plugins run locally in your build.

    How it works

    Minify JavaScript in five steps

    No install or sign-up required. Open the page and minify; add the CLI or a build plugin when you need automation.

    JavaScript minification, without the upload

    JShaman-JSMinify is a free, fast, local JavaScript minifier. Whether you are shipping a personal project, a React app, a Node.js service or a large enterprise frontend, reducing JavaScript size is one of the most direct performance wins.

    What is JavaScript minification?

    Minification removes unnecessary characters and performs equivalent rewrites without changing behavior: comments and whitespace, long variable names, unreachable code, true → !0, merged declarations and more.

    Why use an AST instead of regex?

    Regex replacements can damage strings, template literals or regular expressions, and cannot reason about side effects. JShaman-JSMinify parses source into a Babel AST first, then compresses, renames and prints it — so modern syntax is handled correctly and unused code is removed safely.

    How much smaller will my code be?

    It depends on the input: comment-heavy, whitespace-heavy files with long names often shrink by 30%–70%. Already-minified or string-heavy projects improve less. The tool shows original size, output size and savings so you can judge whether more aggressive options are worth it.

    Minification vs obfuscation

    Minification reduces size; renaming is a side effect. Obfuscation makes code harder to read, often with control-flow transforms. JShaman-JSMinify focuses on minification and optional mangling; it is not a control-flow obfuscator, and obfuscation should not be treated as a security boundary.

    Privacy and safety

    Online minification runs entirely in your browser; code is never sent to a server or stored. The CLI, Node API and build plugins run only on your machine or in CI.

    01 Quick start▾

    Online

    Paste code into the editor above, choose options and click Minify JavaScript. Everything runs locally in the browser.

    CLI

    Requires Node.js 12 or newer.

    npm install -g jshaman-jsminify

jshaman-jsminify input.js -o input.min.js
jshaman-jsminify a.js b.js -c -m -o bundle.min.js
jshaman-jsminify -c -m < input.js > input.min.js
jshaman-jsminify app.js -o app.min.js --source-map

    Node API

    const { minify } = require("jshaman-jsminify");

const result = minify(source, {
	compress: { drop_console: true, passes: 2 },
	mangle: { toplevel: true },
	output: { comments: false },
	sourceMap: { filename: "app.min.js", url: "app.min.js.map" }
});

if (result.error) throw result.error;
console.log(result.code);

    03 Node API▾

    minify(source, options)

    Returns { code, map, error, warnings, reports, stats }. It does not throw for minification failures; check result.error.

    const { minify } = require("jshaman-jsminify");

const result = minify(source, {
	target: "es5",
	compress: true,
	mangle: true,
	sourceMap: true
});

    Output target

    target accepts es5, es2015 … es2022 and esnext. Downleveling uses Babel preset-env; it converts syntax only and does not inject polyfills or bundle modules.

    Other exports

    parse, transform, generate, minifyAst, defaultOptions and version are also available.

    04 Options overview▾

    All options are optional. Defaults below match the library; the online UI turns on a safe subset.

    GroupWhat it controls
    compress38 optimizations: dead code, side effects, sequences, conditionals, loops, switches, inlining, constant folding, unsafe rewrites
    mangleVariable/function renaming, top-level scope, reserved names, class names and property mangling
    outputComments, beautify, quotes, ASCII, preamble, shebang, line length, indentation, semicolons
    parseSource type, parser plugins, expression mode, return outside function
    targetES5 / ES2015 … ES2022 / ESNext syntax downleveling
    sourceMap / nameCacheSource map generation and stable renaming across builds

    Safe defaults are used for production. drop_console, unsafe_*, top-level mangling and property mangling are opt-in.

    Full option reference

    compress — optimization

    OptionDefaultDescription
    compress.unusedtrueRemove unused local functions and variables.
    compress.toplevelfalseAlso compress and mangle top-level declarations.
    compress.dead_codetrueRemove code after return, throw and other unreachable code.
    compress.side_effectstrueDrop expressions and statements with no side effects.
    compress.join_varstrueMerge adjacent var, let and const declarations.
    compress.sequencestrueMerge consecutive expression statements into comma sequences.
    compress.if_returntrueMerge if/return branches where equivalent.
    compress.booleanstrueRewrite true to !0 and false to !1.
    compress.assignmentstrueSimplify assignments and increment/decrement expressions.
    compress.directivestrueDeduplicate directive prologues such as use strict.
    compress.loopstrueSimplify while(true), for(;;), do-while(false) and similar loops.
    compress.switchestrueRemove trailing breaks and convert simple switches to if.
    compress.inlinetrueInline simple single-use functions with a single return.
    compress.argumentstrueRewrite arguments[0] to the corresponding parameter name.
    compress.arrowsfalseConvert function callbacks to arrow functions (ES6+, opt-in).
    compress.hoist_funsfalseMove function declarations to the top of their scope.
    compress.hoist_varsfalseMerge nested var declarations into the function top.
    compress.unsafe_undefinedfalseReplace undefined references with void 0 (unsafe if shadowed).
    compress.unsafe_mathfalseRewrite Math.pow(x, 2) and x ** 2 as multiplication (unsafe).
    compress.unsafe_protofalseRewrite prototype access (unsafe).
    compress.unsafe_regexpfalseConvert RegExp constructors to regular expression literals.
    compress.propertiestrueSimplify property access such as o["a"] to o.a.
    compress.empty_statementtrueRemove empty statements and empty else branches.
    compress.conditionalstrueConvert if statements to ternaries or short-circuit expressions.
    compress.inline_literalstrueInline constant references at their use sites.
    compress.collapse_varstrueMerge single-use variables into their use sites.
    compress.reduce_varstruePropagate single-assignment constant variables.
    compress.evaluatetrueFold constant expressions such as 1 + 2 to 3.
    compress.drop_debuggertrueRemove debugger statements.
    compress.drop_consolefalseRemove console.* calls. This changes runtime behavior.
    compress.pure_gettersfalseTreat property reads as pure and remove them when safe (unsafe).
    compress.keep_fargstrueKeep unused function parameters (safer).
    compress.pure_funcs[]Function calls that may be removed when their result is unused.
    compress.passes1Number of compression passes. The web UI uses 2 by default.
    compress.unused_functionsnullOverride unused handling for functions: true or false.
    compress.unused_variablesnullOverride unused handling for variables: true or false.
    compress.unused_toplevel_functionsnullOverride unused handling for top-level functions.
    compress.unused_toplevel_variablesnullOverride unused handling for top-level variables.

    OptionDefaultDescription

    mangle.functionstrueRename local functions to short names.

    mangle.keep_classnamesfalseDo not rename class names.

    05 Source maps & nameCache▾

    Generate an external map, inline it as a data URI, or chain an upstream map. nameCache keeps renamed identifiers consistent across multiple builds.

    const result = minify(source, {
	sourceMap: {
		filename: "app.min.js",
		url: "app.min.js.map",
		includeSources: true
	},
	nameCache: {}
});
    06 Compatibility & ES targets▾
    • Runtime: Node.js 12+; the browser build needs a modern ES2018 browser.
    • ES output: target uses Babel preset-env for syntax downleveling. It does not inject Promise / Object.assign polyfills and does not bundle modules. ES5 output may add helpers and grow.
    • Top-level names: kept by default because they may be global APIs; enable toplevel only when safe.
    • Property mangling: can affect JSON, in checks and external callers; limit it with regex and reserved.
    • unsafe_*, arrows and pure_getters are opt-in.
    • With eval / with, scope-dependent optimizations degrade and emit a warning.
    Build tools

    Build-tool plugins

    Use the same minifier in webpack, rollup or Vite. The adapters are included in the npm package.

    01 webpack plugin▾

    Works with webpack 5 and webpack 4. Options are the same as the minifier, plus test, include, exclude, sourceMap and report.

    const JsMinifyPlugin = require("jshaman-jsminify/integrations/webpack");

module.exports = {
	mode: "production",
	optimization: {
		minimize: true,
		minimizer: [new JsMinifyPlugin({ compress: { passes: 2 }, mangle: { toplevel: true } })]
	}
};

    For webpack 4, set optimization.minimize: false and add the plugin to plugins.

    02 rollup plugin▾ 
    const jsminify = require("jshaman-jsminify/integrations/rollup");

module.exports = {
	input: "src/index.js",
	output: { file: "dist/bundle.js", format: "cjs", sourcemap: true },
	plugins: [jsminify({ compress: { passes: 2 } })]
};
    03 Vite plugin▾

    Runs during build. Disable Vite's built-in minifier so esbuild does not minify twice.

    const jsminify = require("jshaman-jsminify/integrations/vite");

export default {
	build: { minify: false },
	plugins: [jsminify({ compress: { passes: 2 } })]
};

    About

    About JShaman-JSMinify

    A free, local-first JavaScript minifier built for production output.

    Built for production JavaScript

    JShaman-JSMinify parses source into a Babel AST, then removes unused and unreachable code, merges declarations and expressions, folds constants, inlines simple functions, shortens names and prints compact output. It is a real minifier, not a text replacement.

    What it includes

    • 38 compression optimizations covering dead code, side effects, conditionals, loops, switches, inlining and constant folding
    • 70+ configurable options for compression, mangling, output, parsing, compatibility and source maps
    • Variable, function and property mangling with reserved lists and property regexes
    • Production output: source maps, nameCache, IIFE wrapping, ASCII escaping, quotes, semicolons and indentation
    • Multiple entry points: browser UI, CLI, Node API and webpack / rollup / Vite plugins
    • Privacy: online minification stays in the browser; code is never uploaded or stored

    Who it is for

    Developers who need to minify a single script quickly, teams adding a minification step to CI, and projects that want an alternative to a full build-tool setup. Node.js 12+ is enough for the CLI and API.
