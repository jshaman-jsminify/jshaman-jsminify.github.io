    Why JShaman-JSMinify

    Why choose JShaman-JSMinify

    Not a regex replacement: a complete Babel-AST minification pipeline that balances size, safety and modern syntax.

    Comment & whitespace cleanup

    Remove // and /* */ comments, collapse indentation, spaces and line breaks while preserving strings and template literals.

    console / debugger removal

    Remove console.log, warn, error and leftover debugger statements when those options are enabled.

    Variable, function and property mangling

    Assign short names by character frequency, with top-level renaming, reserved lists, class-name protection and property-regex mangling.

    AST-level optimization

    Remove unreachable code, merge declarations and expressions, fold constants, inline single-use variables and simple functions, and turn ifs into ternaries or short-circuits.

    Boolean and expression compression

    true → !0, false → !1, undefined → void 0, plus optional Math.pow / ** rewrites.

    ES5 to ES2022+

    Parse modern syntax and optionally downlevel the output to ES5, ES2015, ES2020 or another target.

    Source maps and nameCache

    Generate, inline and chain source maps; keep renaming stable across builds with nameCache.

    100% browser-local

    Online minification runs entirely in your browser; code is never uploaded. CLI and plugins run locally in your build.

    How it works

    Minify JavaScript in five steps

    No install or sign-up required. Open the page and minify; add the CLI or a build plugin when you need automation.

    Paste or open code

    Paste JavaScript above, click “Open file” to choose a .js file, or drag a file into the editor.

    Copy or download

    Copy the result or download .js; when source maps are enabled you can download the .map file too.

    JavaScript minification, without the upload

    JShaman-JSMinify is a free, fast, local JavaScript minifier. Whether you are shipping a personal project, a React app, a Node.js service or a large enterprise frontend, reducing JavaScript size is one of the most direct performance wins.

    What is JavaScript minification?

    Minification removes unnecessary characters and performs equivalent rewrites without changing behavior: comments and whitespace, long variable names, unreachable code, true → !0, merged declarations and more.

    Why use an AST instead of regex?

    Regex replacements can damage strings, template literals or regular expressions, and cannot reason about side effects. JShaman-JSMinify parses source into a Babel AST first, then compresses, renames and prints it — so modern syntax is handled correctly and unused code is removed safely.

    How much smaller will my code be?

    It depends on the input: comment-heavy, whitespace-heavy files with long names often shrink by 30%–70%. Already-minified or string-heavy projects improve less. The tool shows original size, output size and savings so you can judge whether more aggressive options are worth it.

    Minification vs obfuscation

    Minification reduces size; renaming is a side effect. Obfuscation makes code harder to read, often with control-flow transforms. JShaman-JSMinify focuses on minification and optional mangling; it is not a control-flow obfuscator, and obfuscation should not be treated as a security boundary.

    Privacy and safety

    Online minification runs entirely in your browser; code is never sent to a server or stored. The CLI, Node API and build plugins run only on your machine or in CI.

    01 Quick start▾

    Online

    Paste code into the editor above, choose options and click Minify JavaScript. Everything runs locally in the browser.

    CLI

    Requires Node.js 12 or newer.

    npm install -g jshaman-jsminify

jshaman-jsminify input.js -o input.min.js
jshaman-jsminify a.js b.js -c -m -o bundle.min.js
jshaman-jsminify -c -m < input.js > input.min.js
jshaman-jsminify app.js -o app.min.js --source-map

    Node API

    const { minify } = require("jshaman-jsminify");

const result = minify(source, {
	compress: { drop_console: true, passes: 2 },
	mangle: { toplevel: true },
	output: { comments: false },
	sourceMap: { filename: "app.min.js", url: "app.min.js.map" }
});

if (result.error) throw result.error;
console.log(result.code);

    03 Node API▾

    minify(source, options)

    Returns { code, map, error, warnings, reports, stats }. It does not throw for minification failures; check result.error.

    const { minify } = require("jshaman-jsminify");

const result = minify(source, {
	target: "es5",
	compress: true,
	mangle: true,
	sourceMap: true
});

    Output target

    target accepts es5, es2015 … es2022 and esnext. Downleveling uses Babel preset-env; it converts syntax only and does not inject polyfills or bundle modules.

    Other exports

    parse, transform, generate, minifyAst, defaultOptions and version are also available.

    04 Full options reference▾

    All options are optional. Defaults below match the library; the online UI turns on a safe subset.

    Full option reference

    compress — optimization

    OptionDefaultDescriptionExample
    compress.unusedtrueRemove unused local functions and variables.function unused(){} → removed
    compress.toplevelfalseAlso compress and mangle top-level declarations.var G=1 → var e=1
    compress.dead_codetrueRemove code after return, throw and other unreachable code.return 1; work() → return 1
    compress.side_effectstrueDrop expressions and statements with no side effects.1+2; → removed
    compress.join_varstrueMerge adjacent var, let and const declarations.var a=1; var b=2 → var a=1,b=2
    compress.sequencestrueMerge consecutive expression statements into comma sequences.a(); b() → a(),b()
    compress.if_returntrueMerge if/return branches where equivalent.if(x)return 1;return 2 → return x?1:2
    compress.booleanstrueRewrite true to !0 and false to !1.true → !0, false → !1
    compress.assignmentstrueSimplify assignments and increment/decrement expressions.a=a+1 → a++
    compress.directivestrueDeduplicate directive prologues such as use strict.Repeated "use strict" → one
    compress.loopstrueSimplify while(true), for(;;), do-while(false) and similar loops.while(true){} → for(;;){}
    compress.switchestrueRemove trailing breaks and convert simple switches to if.switch(x){case 1:return 1;break} → if(x===1)return 1
    compress.inlinetrueInline simple single-use functions with a single return.function f(){return 1} f() → 1
    compress.argumentstrueRewrite arguments[0] to the corresponding parameter name.arguments[0] → parameter name
    compress.arrowsfalseConvert function callbacks to arrow functions (ES6+, opt-in).function(){return 1} → ()=>1
    compress.hoist_funsfalseMove function declarations to the top of their scope.Function declarations moved to scope top
    compress.hoist_varsfalseMerge nested var declarations into the function top.if(x){var a=1} → var a; if(x)a=1
    compress.unsafe_undefinedfalseReplace undefined references with void 0 (unsafe if shadowed).undefined → void 0
    compress.unsafe_mathfalseRewrite Math.pow(x, 2) and x ** 2 as multiplication (unsafe).x**2 → x*x
    compress.unsafe_protofalseRewrite prototype access (unsafe).Array.prototype.slice → [].slice
    compress.unsafe_regexpfalseConvert RegExp constructors to regular expression literals.new RegExp("a") → /a/
    compress.propertiestrueSimplify property access such as o["a"] to o.a.o["a"] → o.a
    compress.empty_statementtrueRemove empty statements and empty else branches.if(x){}else y() → if(!x)y()
    compress.conditionalstrueConvert if statements to ternaries or short-circuit expressions.if(x)y() → x&&y()
    compress.inline_literalstrueInline constant references at their use sites.var X=1; f(X) → f(1)
    compress.collapse_varstrueMerge single-use variables into their use sites.var a=f(); g(a) → g(f())
    compress.reduce_varstruePropagate single-assignment constant variables.var a=1; f(a) → f(1)
    compress.evaluatetrueFold constant expressions such as 1 + 2 to 3.1+2 → 3
    compress.drop_debuggertrueRemove debugger statements.debugger → removed
    compress.drop_consolefalseRemove console.* calls. This changes runtime behavior.console.log(1) → removed
    compress.pure_gettersfalseTreat property reads as pure and remove them when safe (unsafe).obj.x; → removed (unsafe)
    compress.keep_fargstrueKeep unused function parameters (safer).function f(a){} keeps a
    compress.pure_funcs[]Function calls that may be removed when their result is unused.pure() → removed when unused
    compress.passes1Number of compression passes. The web UI uses 2 by default.passes:1 vs passes:2
    compress.unused_functionsnullOverride unused handling for functions: true or false.unused:false, unused_functions:true
    compress.unused_variablesnullOverride unused handling for variables: true or false.unused:false, unused_variables:true
    compress.unused_toplevel_functionsnullOverride unused handling for top-level functions.unused_toplevel_functions:true
    compress.unused_toplevel_variablesnullOverride unused handling for top-level variables.unused_toplevel_variables:true

    05 Source maps & nameCache▾

    Generate an external map, inline it as a data URI, or chain an upstream map. nameCache keeps renamed identifiers consistent across multiple builds.

    const result = minify(source, {
	sourceMap: {
		filename: "app.min.js",
		url: "app.min.js.map",
		includeSources: true
	},
	nameCache: {}
});
    06 Compatibility & ES targets▾
    • Runtime: Node.js 12+; the browser build needs a modern ES2018 browser.
    • ES output: target uses Babel preset-env for syntax downleveling. It does not inject Promise / Object.assign polyfills and does not bundle modules. ES5 output may add helpers and grow.
    • Top-level names: kept by default because they may be global APIs; enable toplevel only when safe.
    • Property mangling: can affect JSON, in checks and external callers; limit it with regex and reserved.
    • unsafe_*, arrows and pure_getters are opt-in.
    • With eval / with, scope-dependent optimizations degrade and emit a warning.
    07 Complete examples▾

    Remove unused code + local mangling

    unused / mangle
    Input
    function app() {
	function unusedHelper() {
		return 42;
	}

	function calc(items) {
		var total = 0;
		for (var i = 0; i < items.length; i++) {
			total += items[i].price * items[i].qty;
		}
		return total;
	}

	console.log(calc([
		{ price: 10, qty: 2 },
		{ price: 5, qty: 4 }
	]));
}
app();
    Output (default options)
    function app(){function t(e){var c=0;
for(var n=0;n<e.length;n++){
c+=e[n].price*e[n].qty
}return c}console.log(t([
{price:10,qty:2},{price:5,qty:4}
]))}app();

    unusedHelper is removed; calc becomes t, items becomes e, total becomes c, and i becomes n.

    Remove console and debugger

    drop_console / drop_debugger
    Input
    function run(value) {
	console.log("debug", value);
	debugger;
	return value * 2;
}
console.warn("legacy");
console.log(run(3));
    Output
    function run(e){return e*2}

    The top-level run function is kept by default. To remove unused top-level functions too, enable toplevel and unused_toplevel_functions.

    Conditionals, booleans and constant folding

    conditionals / if_return / booleans / evaluate
    Input
    function status(ok) {
	if (ok) {
		return true;
	} else {
		return false;
	}
}
console.log(status(1), 1 + 2 * 3);
    Output
    function status(t){return!!t}
console.log(status(1),7);

    Multiple passes apply in pipeline order: if_return → conditionals → booleans → evaluate.

    Turn if/else into a conditional expression

    conditionals
    Input
    function notify(x) {
	if (x) {
		console.log("yes");
	} else {
		console.log("no");
	}
}
notify(true);
notify(false);
    Output
    function notify(o){
	o?console.log("yes"):console.log("no")
}
notify(!0),notify(!1);

    booleans rewrites true / false as !0 / !1, and sequences merges the two calls.

    Chained inlining and multiple passes

    inline / passes
    Input
    function outer(a) {
	function inner(b) {
		return a + b;
	}
	return inner(2);
}
console.log(outer(1));
    Output (toplevel + passes: 2)
    console.log(3);

    With one pass the output is function outer(n){return n+2}console.log(outer(1));. The second pass completes the outer inlining.

    Property mangling with a regex filter

    mangle.properties
    Input
    var user = {
	_secret: "x",
	name: "Tom"
};
console.log(user._secret, user.name);
    Output (regex: /^_/)
    var user={e:"x",name:"Tom"};
console.log(user.e,user.name);

    Property mangling changes object keys and may affect JSON serialization or external callers. Use reserved and regex limits.

    The risk of top-level mangling

    toplevel / mangle.toplevel
    Input
    var MyLibrary = {
	version: "1.0.0"
};
console.log(MyLibrary.version);
    Output (toplevel: true)
    console.log({version:"1.0.0"}.version);

    The default output keeps var MyLibrary={version:"1.0.0"};console.log(MyLibrary.version); and preserves the global name. Enable top-level processing only when there are no external references.

    Output formatting combination

    beautify / quote_style / semicolons / indent_start
    Options
    output: {
	beautify: true,
	quote_style: "single",
	semicolons: false,
	indent_start: 2
}
    Output
      var s = 'a'
  s && console.log(s)

    Optional semicolons are omitted only where ASI is safe. A line starting with (, [, / and similar keeps its semicolon.

    Build tools

    Build-tool plugins

    Use the same minifier in webpack, rollup or Vite. The adapters are included in the npm package.

    01 webpack plugin▾

    Works with webpack 5 and webpack 4. Options are the same as the minifier, plus test, include, exclude, sourceMap and report.

    const JsMinifyPlugin = require("jshaman-jsminify/integrations/webpack");

module.exports = {
	mode: "production",
	optimization: {
		minimize: true,
		minimizer: [new JsMinifyPlugin({ compress: { passes: 2 }, mangle: { toplevel: true } })]
	}
};

    For webpack 4, set optimization.minimize: false and add the plugin to plugins.

    02 rollup plugin▾ 
    const jsminify = require("jshaman-jsminify/integrations/rollup");

module.exports = {
	input: "src/index.js",
	output: { file: "dist/bundle.js", format: "cjs", sourcemap: true },
	plugins: [jsminify({ compress: { passes: 2 } })]
};
    03 Vite plugin▾

    Runs during build. Disable Vite's built-in minifier so esbuild does not minify twice.

    const jsminify = require("jshaman-jsminify/integrations/vite");

export default {
	build: { minify: false },
	plugins: [jsminify({ compress: { passes: 2 } })]
};

    About JShaman-JSMinify

    A free, local-first JavaScript minifier built for production output.

    Built for production JavaScript

    JShaman-JSMinify parses source into a Babel AST, then removes unused and unreachable code, merges declarations and expressions, folds constants, inlines simple functions, shortens names and prints compact output. It is a real minifier, not a text replacement.

    • 38 compression optimizations covering dead code, side effects, conditionals, loops, switches, inlining and constant folding
    • 70+ configurable options for compression, mangling, output, parsing, compatibility and source maps
    • Variable, function and property mangling with reserved lists and property regexes
    • Production output: source maps, nameCache, IIFE wrapping, ASCII escaping, quotes, semicolons and indentation
    • Multiple entry points: browser UI, CLI, Node API and webpack / rollup / Vite plugins
    • Privacy: online minification stays in the browser; code is never uploaded or stored
